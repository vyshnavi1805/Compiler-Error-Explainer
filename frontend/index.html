C Compiler Error Explainer

Compiler Design Lab Project

An educational compiler-analysis system designed to demonstrate the six major phases of compilation and provide rule-based explanations of compiler errors. This project contains no AI, no machine learning, and no external API calls — every explanation is generated from a fixed rule database matched against the compiler's own analysis, and the entire application runs fully offline.
